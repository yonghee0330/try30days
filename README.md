# Try30Days 파일럿 앱

부모와 아이가 습관을 하나씩 걸고 30일 동안 서로 확인 도장을 찍는 가족 챌린지 웹앱입니다.
**바로 쓰기: https://yonghee0330.github.io/try30days/**

부모 휴대폰 한 대에 홈 화면 앱으로 설치해서 씁니다. 가입이 없고, 모든 기록은 그 휴대폰 브라우저 안에만 저장됩니다.

## 되는 것
- 시작 설정: 부모 호칭, 아이 닉네임, 습관 짝(프리셋 또는 직접 쓰기), 집 형태와 아이 방 색, 보상 약속서 서명, 시작일
- 매일: 각자 체크 → 상대가 확인 도장 → 가족 스트릭. 어제 기록은 다음 날까지 고칠 수 있음
- 3D 우리 집: 실제 기록대로 책장, 장난감, 별 모빌, 식탁 휴대폰, TV/보드게임, 등불, 가족 나무가 바뀜. 17시 전에는 아침, 이후에는 저녁 조명
- 놓친 날: 다음 날 그 사람 방이 살짝 흐려짐. 회복권 2장으로 메울 수 있음
- 3·10·20일차 응원 미션, 7일차 파일럿 설문(계속 의향, 적정 가격)
- 달력, 보상 이행 체크(30일차부터), 완주 리포트 이미지 저장·공유
- 더보기: 캘린더 알림 파일(.ics), 파일럿 요약 복사, 백업 저장·불러오기, 테스트용 날짜 넘기기
- 3D를 못 띄우는 휴대폰에서는 같은 장면을 2D 그림으로 보여 줌

## 안 되는 것 (서버가 없어서)
- 엄마·아빠 휴대폰 두 대에서 같은 기록 보기
- 앱이 직접 보내는 푸시 알림 (대신 캘린더 알림 파일 제공)
- 결제
- 휴대폰을 바꾸거나 브라우저 데이터를 지우면 기록이 사라짐 (백업 파일로 옮길 수 있음)

## 내 컴퓨터에서 실행
```bash
cd "try30days-app"
python3 -m http.server 5173
```
브라우저에서 http://localhost:5173 을 엽니다. 파일을 더블클릭해서 열면(file://) 동작하지 않습니다.

## 파일럿 가족에게 나눠 주기
휴대폰에서 쓰려면 https 주소가 필요합니다. 가장 쉬운 방법:
1. https://app.netlify.com/drop 에 접속해 `try30days-app` 폴더를 통째로 끌어다 놓습니다.
2. 나온 주소를 가족들에게 보냅니다.
3. 아이폰은 Safari에서 열고 공유 버튼 → "홈 화면에 추가". 안드로이드는 Chrome 메뉴 → "앱 설치".

GitHub Pages, Vercel도 같은 방식으로 올릴 수 있습니다(빌드 과정 없음).

## 파일럿 운영 팁
- 가족들에게 일주일에 한 번 "더보기 → 파일럿 기록 보내기 → 요약 복사"를 눌러 카톡방에 붙여 달라고 하면, 완주율·보상 이행·결제 의향·이탈 날짜를 한 곳에 모을 수 있습니다.
- 처음 보여 줄 때는 시작 화면의 "예시 가족으로 둘러보기"로 12일째 모습을 먼저 보여 주세요.

## 파일 구성
- `index.html` 앱 껍데기, `css/app.css` 스타일
- `js/store.js` 기록 저장과 계산(스트릭, 회복권, 3D에 넘길 값)
- `js/app.js` 화면과 버튼 동작
- `js/house3d.js` Three.js 0.160.0 3D 집 (CDN에서 불러옴)
- `js/report.js` 완주 리포트 이미지
- `sw.js`, `manifest.webmanifest`, `icons/` 홈 화면 설치와 오프라인 실행
